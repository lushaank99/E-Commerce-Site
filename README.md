# E-Commerce-Site
Creating a website that should be able to buy various items (clothes) from the site. 

Admin Page is where user can be able to update, create stock and delete stock with local database.
Frontend Page is displayed on the webpage which has the UI and details related to the products and other items.
Added Admin Page to be added to the Database instead of storing the data locally.

Remove node modules from all three folders admin, frontend and backend

Install Node, React
install node(npm, npx)
npm install react-router-dom
npm install express
npm install jsonwebtoken
npm install mongoose
npm install multer
npm install cors
npm create vite@latest . (with React and JavaScript)
